Project Name: Survive The Night — 2D Psychological Horror Prototype

Genre: Single-Player 2D Top-Down Horror prototype for PC

Engine: Unity Engine


How To Run the Game:

1. Extract the .zip archive to your preferred directory.
2. Open the extracted folder and locate UXG2502_SurviveTheNight.exe.
3. Double-click UXG2502_SurviveTheNight.exe to launch the game. (Note: If Windows SmartScreen displays a warning, click "More Info" and select "Run Away".)
4. The Game starts running and may you have the best horror experience with Survive The Night. Enjoy!

Recommended Audio Settings:

For the optimal horror experience
- Wear stereo headphones / earphones to accurately detect directional audio panning (Enemy positioning).
- There is Audio Settings in the Game settings for players to adjust to their preferred gaming experience.


Controls:

Movement - W A S D

Camera View - Mouse / Trackpad

Interact - E

Collect / Pickup - Auto-Pickup

QTE Escape Prompt - Spacebar

Pause Menu - Esc
